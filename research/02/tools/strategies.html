Strategy sweep

Plays every strategy in a fixed grid on weather seeds 1–80 with the game's own model, run headless. Serve the repository root (python -m http.server) and open /research/02/tools/strategies.html. It takes a few minutes. Write-up: research/02/notes/strategies-2026-11-18.md.

A strategy is: which improvements to build in harvest 1; chuño crews in the Inca years; how the other crews are placed ("best": Valley, Upper fields, High grain, Puna, each up to its room; "spread": one crew per zone in turn); and, after 1573, chuño crews, Potosí wage crews and the same placing rule.
