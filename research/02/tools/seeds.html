Seed screen

Screens weather seeds for the difficulty presets with the game's own model, run headless. For each seed it plays the default plan twice ("Best land first" and "Keep the same shares" at each re-plan) and all 2,304 tested plans (the same grid as the end screen's comparison), and reports colonial food (harvests 4–6), hunger deaths and welfare. Serve the repository root (python -m http.server) and open /research/02/tools/seeds.html. Seeds 1–2000 take about four minutes. Write-up: docs/hard-mode-2026-11-18.md.
