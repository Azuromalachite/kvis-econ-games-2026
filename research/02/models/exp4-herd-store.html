Experiment 4: does a herd kept as a living food store change outcomes, strategies or the lesson?

Pre-registration: research/pre-registrations/2026-11-19-herd-store.md (merged in #49 before this page existed). Serve the repository root (python -m http.server) and open /research/02/models/exp4-herd-store.html. It uses the game's own model, read from frost-and-silver.html and never changed, with six textual replacements, each a no-op when nobody slaughters and the herd is full:

  1. weather is drawn from a weather index S.wxYear instead of the harvest number;
  2. inside a block the harvest number (which keys silver, resettlement and the 1585–91 epidemic) is held;
  3. the epidemic fires only when the harvest number moves to 5;
  4. Puna output is scaled by the herd's share of its carrying capacity Hd / K;
  5. meat from slaughter is added to the harvest's food, before stores and the eating cap;
  6. the same meat is added to the same-weather Inca-rules counterfactual (the lesson test).

Herd regrowth, dry-year loss, the carrying capacity under resettlement, the policies and the GDP value of herd growth are computed here, outside the game. The first step checks that with 1-year blocks and no slaughter the model reproduces the game exactly on every seed; if not, nothing else is reported.
